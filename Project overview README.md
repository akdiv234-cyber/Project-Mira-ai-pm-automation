# Nexora AI Project Management Automation Platform

## Project Overview

An AI-powered Project Management and Program Delivery Automation Platform developed using n8n, AI agents, Jira, Gmail and Langfuse.

The platform automates key PM/TPM activities, including project planning, risk identification, validation, approval management and weekly status reporting.

## Business Scenario

Nexora Pvt. Ltd. is delivering an AI Adoption Project for ABCDE Ltd., a logistics and supply chain company.

The project focuses on four capabilities:

- Demand Forecasting
- Route Optimization
- Inventory Management
- Customer Support
